# 配信スライドメーカー

学術系 VTuber など、配信で解説をする人のためのスライド作成ツールです。
テンプレートと配色を選んで文字や画像を入れるだけで、程よくポップで読みやすいスライドが作れます。

## サンプル

- [配信用ページ（HTML）](public/samples/slidemaker_sample.html) … ブラウザで開くと、スライドの下に配信用メモが表示されます
- [PDF](public/samples/slidemaker_sample.pdf) … 段階表示の各ステップを1ページずつにしたもの

> GitHub 上では HTML はソースとして表示されます。実際の見た目は、公開ページの「サンプル」から開くか、ファイルをダウンロードしてブラウザで開いてください。

## 使い方

1. ツールを開き、ページを追加して文字や画像を入れます（`>>` と書くと、その後ろはクリックで順に表示されます）。
2. 「配信用ページを DL」で保存したファイルをブラウザで開き、OBS でスライドの部分を切り取って配信に載せます。
3. スライドを共有するときは「スライドを PDF で DL」で保存し、都合のよい方法で渡してください。

入力した文章や画像はどこにも送信されず、すべてブラウザの中だけで処理されます。

## 開発

```sh
npm install
npm run dev     # 開発サーバー
npm run build   # dist/index.html（単一ファイル）を生成
npm test
```
